三个关键判断

  • 眼睛是决定性因素——消融实验表明去掉工具定义或执行结果会直接夺走行动与闭环能力

  • 扩展眼睛和手脚是最主要的能力杠杆——模型固定时重定义观察/动作空间能把不可解任务变为可解

  • 大脑之外仍有竞争力空间——模型能力在商品化

这一页是全书的第一性原理：Agent = LLM + 上下文 + 工具。我们用三个槽位来类比：LLM 是大脑，负责理解与决策，对应学术术语里的策略 Policy；上下文是眼睛，决定每次决策的信息输入，对应观察空间 Observation Space；工具是手脚，决定能对世界做什么改动，对应动作空间 Action Space。底部三个关键判断请记住：眼睛是决定性因素，消融实验表明，去掉工具定义或执行结果会直接夺走行动与闭环能力；模型固定时，扩展眼睛和手脚是最主要的能力杠杆，重定义观察与动作空间能把不可解任务变为可解；大脑之外仍有竞争力空间，因为模型能力正在商品化。标题里的两种形态，一是这页的学术公式，二是下一页的生产形态。后面每一章都在改公式的某个部件——阶段一的验收标准，就是能把任意一个 Agent 产品拆进这三个槽位。
