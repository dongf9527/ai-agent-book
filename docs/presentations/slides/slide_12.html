下半场从第五周到第十周，分三个阶段。阶段四『证据』：精读第 7 章，跑 tau2-bench-eval，核心任务是为 mini agent 预建评估集——10 到 20 条端到端任务，加上轨迹前缀边界任务，定义边界集与保留集，产出评估集 v1。阶段五『创造』：借 coding agent 参照第 1 到 5 章从头实现 mini coding agent，同时进入 GPU 主场，跑 ch8 的 cot-distillation 和 curly-quote-sft；这一阶段的验收标准，是在评估集上取得 Pass^k 可复现的提升。阶段六『进化』：精读第 9、10 章，跑 trajectory-verifier 和 parallel-web-research，为 mini agent 挂上受控更新回路；验收标准是真实失败案例经闭环转化为改进，且不伤保留集。最后这六问自查清单，是每次实验和迭代记录的模板：改了公式哪个部件、属于哪条更新路径且可回滚与风险匹配、五个设计模式出现了几个、边界集和保留集是否都测了、结论有没有数据支撑、安全三层是否被波及。
