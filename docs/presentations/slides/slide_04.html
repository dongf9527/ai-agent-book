怎么用这本书？仓库里是三层资产。第一层是正文 book 目录，10 章共 7300 行 Markdown，可以用 pandoc 加 xelatex 编译成 PDF，用法是通读建立框架；第二层是 chapter1 到 chapter10 的实验目录，109 个可运行实验，用 uv 做依赖管理，extras 提供 ch1~ch10、all、vllm、unsloth 等选项，用法是动手验证概念；第三层是 EXPERIMENT_LEDGER 台账，每个实验都要留下假设、数据、结论构成的证据链，这是学习科研式做实验的范式。三层的配合方式是：读一章正文，跑对应章节的 Starter 实验，再把结果记进自己的台账。我们的学习仓库 fork 自 dongf9527/ai-agent-book，已同步上游全历史，学习笔记统一提交到 docs 目录，方便追溯与复盘。
