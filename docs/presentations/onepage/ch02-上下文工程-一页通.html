第二章是全书最关键的一章：上下文决定 Agent 的能力上限。主线是显式管理信息——上下文等于静态前缀加动态轨迹：System Prompt 与 Tools 字节级不动，user、assistant、tool 消息持续追加在末尾；守住「前缀不改、追加末尾、标准格式」三条铁律，KV Cache 命中就能把单次请求成本降到约十分之一。机制层讲五要素、无状态 API 与缓存即架构约束；内容层讲结构化提示、注入攻防与 Skills 渐进披露；状态层讲状态栏、压缩三动机与隔离优于压缩。核心论断：上下文学习是检索而非推理，状态栏与压缩都是在给它补上提炼层。收尾钩子：仓库实验 1-1 实测双 canonical 缓存命中率 Ollama 80.6%、Kimi 48.0%，欢迎对照 docs/guide 学习路径复现。
