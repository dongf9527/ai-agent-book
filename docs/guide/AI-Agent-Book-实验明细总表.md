## blocked 项替代路径速查（红线兼容，逐项）

> 原则：替代 = 换提供方，不换「真实性」——真实服务、真实推理、真实数据；验收门槛被原样满足才可入账，否则只能记「降级复现」且不得标 passed。官方先例：4-1 canonical 用本地 Ollama、2-6 改用 Kimi Code CLI、7-12 documented backend substitutions。判定规则详见主文档 5.1 节。

| 项 | 缺什么 | 替代路径（免云端凭据） |
|---|---|---|
| 4-2 感知工具 ⛔ | DashScope 国际站凭据（多模态取证） | 搜索用自托管 SearXNG / 免 key 源；图片 OCR+分析用本地 VLM（Ollama qwen2.5vl）；音视频转录用本地 whisper；公开数据源（天气/Wikipedia/ArXiv/汇率）本就免注册；私有源用 Radicale（CalDAV）自托管——原书明确五类场景中多数工具基于免注册开放 API |
| 4-4 执行工具 ⛔ | 真实 GUI/桌面面与部分外部系统凭据 | browser-use 本地真实浏览器免凭据；桌面控制用 X11/VNC 虚拟桌面 + 开源 GUI 控制；Android 环节用本地 AVD + 本地 vLLM 模型（7-13 先例即本地模型跑 AndroidWorld）；GitHub PR/邮件/日历用自托管 Gitea/Mailpit/Radicale 或免费层；linter/危险命令审查/长输出截断等安全机制全部纯本地 |
| 4-5 协作工具 ⛔ | 人机协作通道凭据（IM/邮件/Slack） | 子 Agent 管理纯本地多进程；HITL 用本地 CLI/TUI 通道（门槛本就要求超时与默认行为，本地通道即可真实满足）；通知用自托管 Matrix/Mattermost（Docker）+ SMTP 真发；「最小化 vs LLM 生成」两种上下文传递对比不依赖外部服务 |
| 6-1 邮件事件 ⛔ | Unipile 凭据（401，两种认证方式均拒） | 自托管邮件栈（Stalwart 单二进制：SMTP+IMAP+CalDAV，或 Docker mailserver）+ 脚本真实发信产生入站事件——门槛「三个真实入站事件 FIFO 处理」可如实满足；日历冲突场景走 CalDAV。注：该实验另有历史哈希失配遗留（relabel 4-5→6-1），重跑时可一并修复 |
