模型会一层一层吃掉 Harness，但没有吃完的那一天（引后记飞轮）

进入生产形态，公式变成 Agent = Model + Harness。Harness 是模型外围的工程系统，由五部分组成：上下文管理、工具接口、约束、验证、纠正——可以看到，它绝大部分代码都在做约束、验证与纠正这些工程活。为什么说 Harness 是竞争力所在？因为在模型商品化的背景下，大家能用的模型越来越趋同，工程价值正加速向 Harness 转移，Demo 和产品的差距恰恰在 Harness，不在模型。Anthropic 的实验是最直接的证据：不换模型，只改 Harness，准确率就从 52.8% 提升到 66.5%——这组数字是全书演化主线最直接的注脚。当然，模型会一层一层吃掉 Harness，但工程上总有模型暂时做不稳的事，这正是后面要讲的飞轮，没有吃完的那一天。
