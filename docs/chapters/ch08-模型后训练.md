# 第 8 章 　模型后训练 🔴 专家级（全书唯一需 ML 基础）｜ 19 个实验

> 拆分自 [项目结构与十章详解](../2026-10-24-项目结构与十章详解.md) ｜ [返回章节索引](README.md)

**核心问题**：能力如何内化进模型参数——预训练 / Mid-training / SFT / RL 四阶段各自在做什么，何时选 SFT、何时选 RL。**SFT 记忆，RL 泛化；数据与环境比算法更重要**是本章纲目。

**内容脉络**：四阶段全景（SFT 本质是换了数据的"预测下一个词"）→ 经典 RL Agent 到现代 Agent 的动作表示演变 → Mid-training 补知识与基础能力 → SFT 与数据合成（从示范到可训练轨迹）→ 何时选择 Mid-training / SFT / RL → **单轮强化学习：记忆与泛化的对照** → RL 算法（16 次 rollout 到一次参数更新；为什么 LLM RL 优先 On-Policy）→ **RL 环境：从评估到仿真**（造不出环境就让模型扮演环境；环境、任务分布与评估隔离）→ 多轮任务与信用分配 → 工具调用把环境带进 Agent → **蒸馏**（在轨蒸馏让一次 rollout 产生密集监督；On-Policy 自蒸馏）→ 三个真实问题案例（Coding Agent 过早结束、中文引号、编辑文件失败）→ 后训练实践要点。

**实验亮点**：19 个实验覆盖 `cot-distillation`（官方 Starter）、`retool`（工具调用内化）、`MiniMind-pretrain`、`continued-pretraining`、SFT/DPO 系列。**需要 CUDA GPU 与 Python 3.12+**，依赖通过 `--extra vllm` / `--extra unsloth` 安装——这是本地 GPU 资源的用武之地。

**研究方向**：多轮信用分配、环境构造与模型扮演环境、在轨蒸馏样本效率——后训练是把评估发现的问题固化为模型能力的通路。
