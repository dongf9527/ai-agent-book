# 第 3 章 　用户记忆和知识库 🔵 进阶级 ｜ 12 个实验

> 拆分自 [项目结构与十章详解](../guide/2026-10-24-项目结构与十章详解.md) ｜ [返回章节索引](README.md)

**核心问题**：如何让 Agent 在对话结束后仍然记住用户、接入外部知识——把上下文从单次会话延伸为跨会话的持久知识体系。用户记忆（个体尺度）与知识库（群体尺度）共用向量检索、知识压缩等底层技术，面临同样的信息冲突、知识过期、检索不准问题。

**内容脉络**：记忆能力评估（三层次框架 + LoCoMo 基准：平均 300 轮超长对话）→ 记忆层次结构 → 四种渐进式存储格式 → 进阶知识表示：可执行代码 → 记忆框架案例 → 记忆压缩与整理 → 隐私保护（日志脱敏）→ **RAG 基础**（分块 → 稠密嵌入 → 稀疏嵌入 → 混合检索）→ **超越扁平文本**（结构化索引、文件系统范式、知识更新策略）→ **Agentic RAG**（把检索工具化的范式转变）→ 上下文感知检索 → 知识发现 → 多模态记忆。

**实验亮点**：`user-memory` 是完整的记忆系统实现（memory_manager + 后台异步提取 + LoCoMo 评测），可直接改造接入业务；`mem0`/`memobase` 提供商业记忆框架对照；`agentic-rag`、`contextual-retrieval` 覆盖检索前沿。

**研究方向**：记忆的三层次评估框架、冲突解决与时间感知、Agentic RAG 与检索工具化、可执行代码作为记忆载体——记忆系统是当前 Agent 产品差异化的主战场。
