# 第 10 章 　多 Agent 协作 🟠 应用级 ｜ 6 个实验

> 拆分自 [项目结构与十章详解](../2026-10-24-项目结构与十章详解.md) ｜ [返回章节索引](README.md)

**核心问题**：群体智能何时真正高于个体。本章给出**新信息判据**：只有当协作引入了单个 Agent 在生成时拿不到的新信息（审核 Agent 真正跑了测试、读了日志、看了截图），协作才产生价值；多 Agent 的每个设计决策都能在单 Agent 三要素中找到对应。

**内容脉络**：分类框架（上下文共享/独立 × 对等/管理者/去中心化拓扑）→ 共享上下文的协作 → 不共享上下文的协作（Agent 眼中的文件系统、通信与控制）→ 三种拓扑详解（对等：相互制衡与迭代改进；管理者：中心化协调；去中心化）→ **跨组织协作：A2A 协议** → **六种失败模式**（共享文件系统并发冲突、错误级联放大、同质趋同、互相扯皮、循环失控、理解债与认知投降）→ **Agent 社会**（斯坦福 AI 小镇、Agentopia 十年尺度生活模拟、Moltbook 社交网络、Vending-Bench Arena 经济竞争、Pinchwork/RentAHuman Agent 经济、狼人杀信息不对称博弈）。

**实验亮点**：`parallel-web-research`（官方 Starter，message_bus + agents 的协调骨架）、`generative-agents`、`talkact-reproduction`、`book-translation`（本书多语言版的翻译流水线本身就是一个多 Agent 项目）。

**工程启示**：搭多 Agent 前先过三问——任务真需要分工吗？不同 Agent 能拿到不同信息吗？协作收益盖得住 Token、通信与调试成本吗？六种失败模式是现成的架构评审清单。
