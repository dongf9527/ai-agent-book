# 第 1 章 　AI Agent 入门 🟢 入门级 ｜ 4 个实验

> 拆分自 [项目结构与十章详解](../guide/2026-10-24-项目结构与十章详解.md) ｜ [返回章节索引](README.md)

**核心问题**：Agent 到底是什么，什么决定了它的能力强弱。本章从观察空间与动作空间这对接口出发，逐一解剖三要素——LLM（大脑）提供理解与决策，上下文（眼睛）决定每次决策的信息输入，工具（手脚）决定能对世界做什么改动。

**内容脉络**：三要素解剖 → ReAct 循环（推理-行动交替的最小 Agent 形态）→ **Harness 工程：模型之外的竞争力** → 从提示工程到 Loop 工程的范式演进 → 构建有效 Agent 的核心原则 → 模型选型 → 编排模式（工作流 vs 自主）→ 护栏与安全性 → Harness 五要素与全书"构建篇"的对应。

**关键概念**：Harness 五要素（上下文供给、工具接口、约束、验证、纠正）是全书的总纲；编排模式的判断标准——任务路径可枚举用工作流，开放探索才用自主 Agent。

**实验亮点**：`context`（三要素最小实现，官方 Starter 第一课）、`image-gen-workflow`、`search-codegen`、`learning-from-experience`。

**工程启示**：读完应能用一句话回答"Demo 和产品的差距在 Harness 不在模型"，并能在自己的项目里指出这五个要素分别对应哪些代码。
